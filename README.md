# Математика КТЖ 5–9 сынып

Интерактивті күнтізбелік-тақырыптық жоспар (Алгебра / Геометрия бөлек).

## Файлды жүктеу (1 минут)

1. Осы бетке кіріңіз: https://github.com/bekzatov0707-source/math-ktp-5-9
2. **Add file** → **Upload files** басыңыз
3. Компьютерден немесе телефоннан `math_ktp_platform.html` файлын таңдаңыз (немесе `index.html` деп атап жүктеңіз)
4. **Commit changes** басыңыз

## Сілтеме (файл жүктелгеннен кейін)

**Ең ыңғайлы (GitHub Pages):**
1. Репозиторийде **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main**, folder: **/ (root)** → Save
4. 1–2 минуттан кейін ашылады:
   **https://bekzatov0707-source.github.io/math-ktp-5-9/**

Егер файлды `index.html` деп атасаңыз — жоғарыдағы сілтеме бірден жұмыс істейді.

**Немесе raw сілтеме:**
https://raw.githubusercontent.com/bekzatov0707-source/math-ktp-5-9/main/math_ktp_platform.html

(Safari-де raw сілтемені ашқанда «Open in Safari» немесе файлды сақтап ашыңыз.)
